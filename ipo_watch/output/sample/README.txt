⚠️  SAMPLE OUTPUT — NOT MARKET DATA  ⚠️

Every number in this folder came from the synthetic fixture files in
../../fixtures/, not from IPOWatch. The IPO names, dates, price bands, GMPs
and subscription figures are invented purely to demonstrate the output
format and the image design.

Do not share these files. They exist so the format can be reviewed before
the first live run.

A live run writes to output/ (not output/sample/) and only succeeds when
ipowatch.in is reachable.
